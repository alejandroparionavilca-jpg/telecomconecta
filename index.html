TelecomConecta + open5Gcube

En TelecomConecta ahora te explicamos open5Gcube: el framework que te permite crear tu propia red de celular 5G en tu computadora, sin ser una operadora como Movistar o Claro.

¿Qué es open5Gcube? 👇 Cómo se Instala 👇

1. ¿Qué es open5Gcube?

open5Gcube es un framework modular de código abierto diseñado para construir y gestionar laboratorios de redes móviles.

Integra múltiples proyectos de redes móviles de código abierto de 2G, 4G y 5G en un entorno de gestión unificado.

Su propósito es facilitar experimentos reproducibles en investigación, pruebas y educación, permitiendo desplegar redes de acceso radio (RAN), redes centrales (CN) y componentes de soporte de manera personalizable y extensible.

¿Qué problema resuelve?

  • Soluciones comerciales: son estables, pero costosas y cerradas.
  • Soluciones de código abierto: son flexibles, pero tienen curva de aprendizaje alta y problemas de compatibilidad.
  • open5Gcube combina lo mejor de ambos: adaptabilidad del código abierto + facilidad de uso para configuraciones experimentales.

💡 En palabras simples

Es como tener tu propia operadora de celular en tu PC: antena, núcleo, chip SIM y celular, todo con software gratis.

¿Qué relación tiene con Telecomunicaciones?

  • La antena que da señal = gNodeB
  • El cerebro que controla la red = Núcleo 5G (Open5GS)
  • El chip SIM = IMSI, KEY, OPC
  • El celular = UE de UERANSIM

Relevancia para la formación en Telecomunicaciones

  • Democratiza el acceso: experimentar con 5G sin infraestructura costosa.
  • Integra múltiples tecnologías: RAN, núcleo y UE en un solo entorno.
  • Facilita la reproducibilidad: los experimentos se pueden replicar y comparar.
  • Prepara para el mundo laboral: habilidades en Docker, orquestación de servicios y configuración de redes 5G muy demandadas.

2. ¿Cómo Funciona open5Gcube?

open5Gcube funciona con contenedores Docker. Cada parte de la red de celular corre en su propio contenedor, aislado de los demás.

2.1. Contenedores Docker y Docker Compose

  • Aislamiento: Los servicios no interfieren entre sí.
  • Reproducibilidad: Las configuraciones son consistentes en diferentes entornos.
  • Portabilidad: El framework puede desplegarse en diversas plataformas de hardware.

La orquestación remota se hace con SSH y Docker-outside-of-Docker (DooD), para distribuir la carga en múltiples hosts físicos.

2.2. Stacks de Red Pre-construidos

Ejemplo: OpenAirInterface (OAI) como RAN + Open5GS como núcleo. Esta modularidad permite elegir y combinar diferentes implementaciones según la necesidad experimental.

2.3. Redes Virtuales Docker

Red¿Para qué sirve?
corenetComunicación entre las funciones del núcleo. Usa macvlan para asignar IP directo desde la red física.
rannetComunicación entre la RAN y el núcleo.
uenetComunicación de los equipos de usuario (UE).

2.4. WebUI para Control y Monitoreo

  • Configurar, iniciar y detener stacks específicos.
  • Visualizar el estado de salud de los contenedores en tiempo real.
  • Acceder a los logs de los servicios.
  • Gestionar VoLTE basada en Open5GS + Kamailio IMS.
  • Leer y escribir tarjetas SIM mediante pySim.

2.5. Soporte para Hardware SDR y Emulación

Soporta hardware SDR físico (USRP X310 / B210) como configuraciones emuladas.

2.6. Flujo de Trabajo Típico

  1. Preparación: Docker, Docker Compose, SSH.
  2. Clonación: Obtener código desde GitHub.
  3. Configuración: Variables en archivos .env para IPs, PLMN, bandas.
  4. Construcción: make build-cacher-start docker-build-all - varias horas.
  5. Despliegue: Desde WebUI o línea de comandos.
  6. Verificación: Estado de contenedores y conectividad de UEs.
  7. Experimentación: ping, iperf3, captura de tráfico.

3. Componentes Principales Integrados

🧠

Open5GS

Núcleo 5G (5GC) basado en 3GPP. Incluye AMF, SMF, UPF, NRF.

📡

OpenAirInterface (OAI)

RAN que implementa eNB / gNB y UE.

📱

UERANSIM

Simulador de UE y RAN para 5G.

📶

srsRAN

RAN 4G y 5G, compatible con SDR.

📞

osmocom

Proyectos para redes 2G y 3G.

💳

pySim

Herramientas para provisión de tarjetas SIM.

¿Qué hace cada función del núcleo 5G?

Función¿Qué hace?
AMFGestiona acceso y movilidad, registro del UE.
SMFGestiona sesiones y asignación de IP.
UPFTransporta los datos del usuario (internet).
NRFRegistro de funciones de red.
NSSFSelección de slice de red.

4. ¿Cómo se Instala open5Gcube?

4.1. Requisitos - Hardware

ComponenteMínimoRecomendado
CPUx86_64, 4 núcleos8+ núcleos (Intel i9 o superior)
RAM16 GB32 GB (92 GB para experimentos prolongados)
Almacenamiento50 GB libres200 GB
Sistema OperativoUbuntu 22.04 LTSUbuntu 22.04 LTS
Kernel5.15+6.8.0 (con soporte TC-BPF)

4.2. Configuración del BIOS

  1. Hyper-Threading deshabilitado
  2. C-States deshabilitado
  3. Intel SpeedStep deshabilitado
  4. CPU Frequency Control y P-States deshabilitados

4.3. Sistema Operativo

sudo apt install linux-image-lowlatency linux-headers-lowlatency
sudo apt install linux-tools-lowlatency

4.4. Paso 1: Paquetes

sudo apt update && sudo apt upgrade -y
sudo apt install -y linux-tools-common net-tools make git-lfs \
  ca-certificates curl gnupg openssh-server python3-virtualenv

4.5. Paso 2: Clonar Repositorio

git clone https://github.com/open5Gcube/open5Gcube/
cd open5Gcube

4.6. Paso 3: Docker

make system-install-docker
sudo usermod -aG docker $USER

4.7. Paso 4: Servicio de Inicio

make systemd-install-unit

4.8. Paso 5: Construir Imágenes - Varias horas

make build-cacher-start docker-build-all

4.9. Paso 6: Iniciar WebUI

make webui-start

Accede en: http://<IP_del_host> puerto 80

5. Configuración de open5Gcube

Se configura con archivos .env en etc/.

5.1. local.env

CORENET_DRIVER=bridge
USRP_IFACE=enp3s0f0
ENB_HOSTNAME=localhost
GNB_HOSTNAME=localhost

5.2. settings.env

MCC=001
MNC=01
TAC=1
APN=internet
NSSAI_SST=1
NSSAI_SD=ffffff
NR_BAND=78
NR_ARFCN=641280

5.3. uedb.env - Suscriptores SIM

001010000052100 F18E5DB0A8B5B8A0304E9113D121DFE3 E83C9CF73E3B9E82E48005A696E86AD8

5.4. networks.env

Define subredes e IPs estáticas. Normalmente no necesita modificarse.

7. Problemas Comunes y Buenas Prácticas

ProblemaSolución
Contenedores no inicianVerificar docker ps -a y que make docker-build-all se completó
No se puede acceder a WebUIVerificar sudo systemctl status open5gcube-webui y liberar puerto 80
Error SSH a hosts RANEjecutar ssh-copy-id <hostname> desde el Controller
UE no se registraVerificar uedb.env y que el IMSI coincida con UERANSIM
  • Documenta tus .env para reproducibilidad.
  • Usa kernel de baja latencia.
  • Monitorea con ctop y docker stats.
  • Combina stacks según necesidad (OAI + Open5GS, srsRAN + Free5GC).
  • Validado con Samsung Galaxy S25, OnePlus 13, Pixel 9, iPhone 13 Mini, etc.
